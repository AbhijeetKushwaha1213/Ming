The Challenge

The Student's Daily Friction: Cognitive Fragmentation

Why traditional study habits and generic AI chatbots fail learners.

❌ Scattered Multimodal Silos
Lecture slides, 400-page textbooks, lab problem sets, and video recordings live in disconnected folders. Students spend 40% of study time just finding relevant definitions.
❌ The Illusion of Competence
Passive re-reading and highlighting creates an illusion of understanding. Without immediate diagnostic retrieval practice, forgetting curves erase 70% of material within 48 hours.
❌ Generic AI Hallucinations
Standard LLM chatbots generate answers without page references, fabricate non-existent textbook citations, and fail closed-book syllabus boundaries.
❌ Blind Practice Without Diagnosis
Generic flashcard apps treat all errors identically, unable to detect whether an error was a slip, a guess, or a specific conceptual misconception.

Algorithmic Innovation

Scientific Differentiation: Cognitive Modeling

Principled Bayesian modeling and coordinate-level citation verification.

🎯 Coordinate Grounding & Refusal Gate
Ming extracts bounding coordinates for every text block. When an answer is synthesized, the system provides precise page references.

100% Out-of-Domain Refusal Gate: If a student asks questions outside the provided material, Ming explicitly refuses to answer rather than hallucinating external trivia.
🧠 Calibrated Bayesian Knowledge Tracing
Standard cognitive science implementation:
P(L₀) = 0.10 (Prior), P(T) = 0.15 (Learn rate)
P(S) = 0.10 (Slip rate), P(G) = 0.20 (Guess rate)

Calculates whether an answer was a lucky guess ($G=0.20$) or a slip ($S=0.10$), updating probabilistic mastery state: $$P(L_{t+1}) = P(L_t \mid O_t) + (1 - P(L_t \mid O_t))P(T)$$
🔍 Diagnostic Distractor Mapping
Multiple-choice options are generated with explicit misconception tags. When a learner chooses option B, Ming diagnoses the exact flawed heuristic (e.g. confusing virtual addresses with physical page frames) and triggers remedial review.
System Design

Production Architecture & Multi-Tenant Data Plane

Engineered for security, offline resilience, and high throughput.

Client Tier (SPA)
• React 18 + TypeScript + Vite 5
• 1.56 MB entry bundle (-35.8% reduction)
• Local-first offline queue with client-side PII scrubbing
• Responsive sticky bottom mobile navigation
API Gateway & Security
• Node.js Gateway with Sliding-Window Rate Limiting
• Supabase Auth JWT + strict impersonation rejection (403)
• Privacy filter: full prompts & document bodies never logged
• Diagnostic readiness probe (/api/health/ready)
Data Plane & AI Engine
• PostgreSQL + pgvector with HNSW cosine index
• SQLite LibSQL fallback for zero-config dev
• Row-Level Security (RLS) policies per user
• Google Gemini 1.5 Flash + all-MiniLM-L6-v2 embeddings
🛡️ Enterprise Security & Tenant Isolation
Strict tenant isolation enforced at both application middleware and database RLS. Operational logs hash student IDs with SHA-256 (usr_8790eb74). Client-side telemetry queue sanitizes credentials before writing to localStorage.

Responsible AI

Security, Privacy & Responsible AI Safeguards

Built from the ground up to protect student data and prevent AI misuse.

🔒 Multi-Tenant Boundary Enforcement
• Database queries scoped strictly by userId
• PostgreSQL Row-Level Security (RLS) blocks cross-user reads
• API Gateway rejects user impersonation attempts with 403 Forbidden
• Isolated offline queues prevent account switching pollution
🛡️ Zero-PII Telemetry & Redaction
• Passwords, tokens, API keys, documents, and prompts are sanitized client-side before localStorage
• Server-side sanitizer scrubs long texts to [REDACTED]
• Operational structured logs hash user IDs via SHA-256
• Zero raw document contents stored in analytics
🚫 Fail-Closed Refusal Gate
• 100% verified refusal rate on out-of-syllabus topics
• Prevents hallucination of medical, legal, or ungrounded claims
• Refuses to answer rather than inventing misleading facts
⚡ Operational Resilience
• Sliding-window rate limiters across all API gateway categories
• Diagnostic health probe accurately distinguishes missing table vs connection drop without leaking DB credentials
• Dead-letter queue evicts permanent 4xx failures
